# HOW TO RUN

Firstly you'll have to git clone this repository

```
git clone https://github.com/an-iq-too-high/mywiki
```

Then say

```
cd mywiki
```

Then you run it!

***Check releases for execution code***


# PACKAGES REQUIRED

git

python

wikipedia-api

OLLAMA (for 3.0)

termux-api (for 3.75)

# HOW TO INSTALL PACKAGES

*P.S: this can work on termux*

```
pkg install git
```

Then you say:

```
pkg install python
```
And THEN

```
pip install wikipedia-api
```
And for OLLAMA

```
pkg install ollama
```
For to run the background service!

```
ollama serve &
```
